🔑 11 CLÉS API (TOUTES LISTÉES):
─────────────────────────────────────────────────────────────────────────

OBLIGATOIRES (4):
1. VITE_SUPABASE_URL          ← Supabase URL
2. VITE_SUPABASE_ANON_KEY     ← Supabase Clé
3. VITE_TELEGRAM_BOT_TOKEN    ← Bot @BotFather
4. VITE_TELEGRAM_CHAT_ID      ← ID groupe Telegram

RECOMMANDÉES (2):
5. VITE_MONETAG_SITE_ID       ← Site ID Monetag
6. VITE_MONETAG_ENABLED       ← true/false

OPTIONNELLES (5):
7. VITE_IP_API_ENABLED        ← true/false
8. VITE_ANTI_BOT_ENABLED      ← true/false
9. VITE_BLOCK_VPN             ← true/false
10. VITE_BLOCK_DATACENTER     ← true/false
11. VITE_TRACKING_ENABLED     ← true/false
