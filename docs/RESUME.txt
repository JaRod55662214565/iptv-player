🚀 PROCHAINES ÉTAPES (SIMPLE)
================================================================================

ÉTAPE 1: Cloudflare (5 minutes)
├─ Créez un compte gratuit: cloudflare.com
├─ Ajoutez votre domaine
├─ Notez les Nameservers
└─ Mettez à jour Digital Plate (Nameservers)

ÉTAPE 2: GitHub (2 minutes)
├─ Créez un repo "web-iptv"
├─ Poussez ce code
└─ Notez l'URL du repo

ÉTAPE 3: Vercel (3 minutes)
├─ Créez un compte gratuit: vercel.com
├─ Connectez GitHub
├─ Importez le repo
└─ Cliquez "Deploy"

ÉTAPE 4: DNS Cloudflare (2 minutes)
├─ Allez dans Cloudflare DNS
├─ Ajoutez un CNAME record
│  └─ Type: CNAME
│  └─ Name: @
│  └─ Value: cname.vercel-dns.com
└─ Sauvegardez

ÉTAPE 5: Attendre (5-30 minutes)
├─ Propagation DNS
└─ Certificat SSL

ÉTAPE 6: Vérifier
└─ Ouvrez: https://votre-domaine.digital-plate ✅

✨ BON À SAVOIR
================================================================================

1. DNS Propagation
   └─ Les changements DNS peuvent prendre 1-48h
   └─ Généralement 5-30 minutes
   └─ Utilisez whatsmydns.net pour vérifier

2. Certificat SSL
   └─ Généré automatiquement par Cloudflare + Vercel
   └─ Peut prendre 24h en cas de problème
   └─ Vérifier: Vercel Settings → SSL Status

3. Cache Cloudflare
   └─ Les assets (CSS, JS) sont cachés 1 an
   └─ Rafraîchir: Cloudflare → Purge Cache

4. Déploiement continu
   └─ Chaque git push = redéploiement auto
   └─ Vercel → Deployments pour voir l'historique

5. Monitoring
   └─ Vercel Analytics : performance
   └─ Cloudflare Analytics : trafic
   └─ GitHub Actions : CI/CD logs
